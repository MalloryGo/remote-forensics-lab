# 电子物证远程勘验靶场

本场景用于电子物证技能竞赛中的远程服务器勘验。**正式题目、题目材料及答案提交均以比赛系统为准**，本页面只说明靶场环境和基本使用方法。

## 环境说明

本场景包含两台主机：

- **Host 1 / `controlplane`（172.30.1.2）**：参赛队使用的远程勘验工作站。进入场景后默认打开的终端即为该主机。
- **Host 2 / `node01`（172.30.2.2）**：本题需要勘验的目标服务器。

请在 `controlplane` 上使用网络探测、Web 访问、文件下载、数据库分析等方式，对目标服务器开展题目要求范围内的远程勘验。除比赛题目明确要求外，不需要对靶场基础环境本身进行操作。

## 开始前

场景启动后会自动初始化目标服务器，通常需要约 **20～60 秒**。终端出现后可执行：

```bash
cat /tmp/remote-forensics-setup-status.txt
```

当其中显示：

```text
web=ok
tcp_services=ok
```

即可开始作答。如刚进入场景时尚未完成初始化，可稍等片刻后再次查看。

目标服务器地址为：

```text
172.30.2.2
```

可先从目标服务器的网络服务、Web 页面及题目提供的检材入手，根据题目要求逐步固定和关联相关信息。

## Web 页面访问

命令行可直接在 `controlplane` 中使用 `curl`、`wget` 等工具访问目标服务器。

如需使用图形化浏览器，可打开 Killercoda 的 **Traffic / Ports（Traffic Port Accessor）**：

- **Host 1** 对应 `controlplane`（172.30.1.2）
- **Host 2** 对应目标服务器 `node01`（172.30.2.2）

场景同时提供了 **Host 1 的 8080 端口转发**，可用于在浏览器中打开目标 Web 服务。

## 可用工具

工作站会准备本题常用的命令行工具，包括 `nmap`、`curl`、`wget`、`sqlite3`、`sha256sum` 等。参赛队也可以使用系统已有的其他常规工具完成分析。

对下载取得的文件，建议先保存到 `controlplane` 本地，再根据文件类型进行哈希计算、文本检索、数据库查询等操作。

## 注意事项

- 所有正式答案均在比赛系统中提交，本页面不提供答案输入功能。
- 请以题目要求为范围开展操作，不需要破坏或重置目标服务器。
- 场景中的网站、业务数据、账号、订单、资金信息等均为竞赛模拟数据，不连接真实业务系统。
- 如页面访问异常，先确认初始化状态，再检查访问的是 Host 1 还是 Host 2。
- 场景重新启动后会重新初始化，上一实例中的临时操作和下载文件不会保留。

完成环境确认后，即可按照比赛系统中的题目开始远程勘验。
